# Quote a deliberate ruling; paraphrase an aside

## Before

```
Peter is dyslexic (stated 2026-08-13: *"two ds look just as good as one"*).
Doubled letters and similar near-homographs are not reliable signal in what he
types — `considdered`, `hirachy`, `benificial`, `ridgid`, `weather`/`whether`
all appeared in normal use and all meant the obvious thing.
```

## After

```
Peter is dyslexic (told me directly, 2026-08-13). Doubled letters and similar
near-homographs are not reliable signal in what he types — doubled consonants
either way, and `weather`/`whether`-class pairs, all appear in normal use and
all mean the obvious thing.
```

## Why

Peter flagged second thoughts about having quoted the line as he typed it.

A quoted line in a durable record stops illustrating the point and *becomes*
the canonical statement of it — a lot of weight for a passing remark. Worse,
the remark was wry and self-deprecating; the memory is a working instruction.
Quoting the aside put the light-hearted register into the permanent record when
the durable part was only the operational fact.

The specimen list of his actual misspellings had the same defect at a smaller
scale — evidence he had not chosen to offer, preserved verbatim. Generalised to
word *classes*, which carries the same operational value with none of the
specimen quality.

**The rule:** quote when the wording *is* the decision ("driver, not
conductor"; "share the conventions, not the code path"). Paraphrase when the
wording was merely how a fact happened to arrive.
