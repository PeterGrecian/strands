# Strand: strands

The meta-strand: curating the strand system itself and, more broadly, how
Peter's Claude sessions are organised for efficiency. Home of ideas about
the workflow — `cld`, the strand pattern, session ritual, memory hygiene,
housekeeping — as opposed to ideas about any one project. Works on
**`~/super`** (bin/cld, strands/, GLOBAL.md, memory/).

## Session ritual

1. Read `STATE.md` and `IDEAS.md`; triage the inbox with Peter.
2. Work — changes land in super (cld, strands/README.md, strand templates,
   GLOBAL.md) or in other strands' curation files.
3. Session end (or on `dcp`): update STATE.md; keep it curated, not a log.

## Scope notes

- A recurring theme in *another* project belongs in its own strand, not
  here. This strand decides *whether* something becomes a strand and how
  strands work, not the content of them.
- Changes to the strand template should be reflected in existing strands
  and `strands/README.md` together.
